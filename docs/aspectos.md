# Aspectos del proyecto

| Aspecto | Descripción |
|---|---|
| Gestión de disponibilidad de cupos | El sistema debe permitir a los estudiantes consultar la cantidad de cupos disponibles en los viajes publicados por los conductores. |
| Organización del backend | El backend se estructura como un monolito modular, dividido internamente en módulos independientes por funcionalidad, para facilitar el mantenimiento y el trabajo paralelo del equipo. Ver [ADR 0001 - Arquitectura de monolito modular](adr/0001-decisiones-arquitectonicas.md). |
